1

Register the device here

Use the Register New Device section below. Give it a name, optional serial ID, and location. After clicking Generate API Key, copy the key immediately — it will never be shown again.

2

Configure the biometric device

On your device's admin panel (ZKTeco, Hikvision, etc.), set the Push / Webhook URL to:

https://hr.admtechub.com/api/v1/device/events

Add a custom HTTP header:

X-Device-Api-Key: mhrdev_xxxxxxxxxxxxxxxx
3

Link employees to the device

Each employee must enter their Device ID (the ID assigned to their fingerprint on the biometric machine) on their Profile page. They can update it themselves by clicking their avatar → My Profile.

Alternatively, HR can set it via the employee edit form under Employees → Edit.

4

Attendance records appear automatically

Once the device sends a clock-in/out event, it will appear on the Attendance page. If an employee's Device ID doesn't match any record, the event will show in the Sync Errors tab here — you can resolve it after linking the correct employee.
